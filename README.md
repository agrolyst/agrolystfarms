# Agrolyst Farms Website

Premium corporate agribusiness website for livestock, poultry and farm produce.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive styling
- `script.js` — WhatsApp enquiry links and email form

## Before launch
1. In `script.js`, set `WHATSAPP_NUMBER` to the real business WhatsApp number in international digits only. For Nigeria use 234 followed by the number without its leading zero.
2. Set `BUSINESS_EMAIL` and replace the placeholder contact information in `index.html`.
3. Replace stock photos with approved farm photos and verify all product claims.
4. This static website supports WhatsApp/email enquiries but does not process online payments or store orders. For checkout on Hostinger, install WordPress + WooCommerce or use a supported e-commerce plan and configure a payment provider available to your business.
5. Test mobile and desktop before connecting the production domain.
